# Е ТВ · 3D-бродкаст-пакет

Эфирное оформление игрового телеканала Е ТВ: заставка канала, заставки рубрик «Вердикт» и «Гаджетотека» по 15 с, отбивка 5 с и анимация логотипа 5 с (вкладка «Логотип» на странице и сцена в Blender; видео логотипа не отрендерено — его можно собрать `ONLY=4` и `tools/encode.sh`). Фирменные цвета: #080A0F, #111722, #00D9FF, #7A35FF.

## Состав

| Файл | Что это |
| --- | --- |
| `index.html` | Страница с плеером: все ролики рендерятся в браузере на Three.js, есть таймкод, монтажный лист, паспорт каждого ролика и безопасные зоны |
| `video/ETV_01_zastavka_kanala.mp4` | Заставка канала, 15 с |
| `video/ETV_02_verdikt.mp4` | Заставка рубрики «Вердикт», 15 с |
| `video/ETV_03_gadzhetoteka.mp4` | Заставка рубрики «Гаджетотека», 15 с |
| `video/ETV_04_otbivka.mp4` | Отбивка, 5 с |
| `tools/render.cjs` | Покадровый экспорт страницы в PNG |
| `tools/encode.sh` | Сборка MP4 из кадров |
| `blender/ETV_animatic_*.blend` | Аниматики всех четырёх роликов для Blender: геометрия без материалов и света, анимация, камера со склейками, надписи текстом |
| `blender/ETV_logo.blend` | Сцена анимации логотипа для Blender: материалы, свет, камера, анимация, рендер Eevee |
| `blender/ETV_animatic_*.mp4` | Превью аниматиков, отрендеренные из этих файлов (Workbench, 960×540) |
| `tools/animatic/` | Выгрузка сцен из страницы и сборка файлов Blender |

Все видео 1920×1080, 30 к/с, H.264, без звука.

## Как посмотреть

Откройте `index.html` в браузере. Нужен интернет: Three.js, библиотека polygon-clipping и шрифты грузятся с CDN.

## Как перерендерить видео

Нужны Node.js 18+ и ffmpeg.

```bash
npm install
npx playwright install chromium
npm run render                                # кадры в frames/
for k in 0 1 2 3; do K=$k N=4 node tools/render.cjs & done; wait   # то же в 4 потока
npm run encode                                # MP4 в video/
```

`ONLY=0,3` рендерит только выбранные ролики (0 — заставка канала, 1 — «Вердикт», 2 — «Гаджетотека», 3 — отбивка, 4 — логотип). Готовые кадры пропускаются, прерванный рендер докатывается повторным запуском. Рендер идёт программно, без видеокарты, около 3,5 часа на весь пакет в 4 потока.

## Аниматик в Blender

В папке `blender/` лежат аниматики четырёх роликов (заставка канала, «Вердикт», «Гаджетотека», отбивка) и сцена анимации логотипа. Они сохранены в Blender 5.2 LTS и открываются в Blender 5.x.

Что внутри каждого файла:

- **Геометрия.** Вся геометрия ролика без материалов и источников света. Главные предметы подписаны по-русски: «Консоль», «Штамп», «VR-шлем», «Крышка» и так далее.
- **Анимация.** Покадровые ключи всех движущихся предметов, 30 к/с. Появление и исчезновение сделано масштабом.
- **Камера.** Ключи на каждый кадр, склейки без интерполяции. Фокусное расстояние, дистанция фокуса и смещение объектива (shift X/Y, композиция по третям) тоже анимированы.
- **Маркеры.** На шкале времени отмечены склейки «План N» и события монтажного листа.
- **Титры и надписи.** Финальные титры и все надписи из роликов — экраны монитора и портативной консоли, табло оценки, бланк рецензии, таблички картриджей, гравировки — это текстовые объекты тем же шрифтом (Unbounded, JetBrains Mono) и того же размера, что в ролике, на тех же местах. Надписи на экранах, которые меняются по ходу ролика, появляются и исчезают по кадрам. Символы, которых нет в этих шрифтах (например, ▸), набраны запасным шрифтом DejaVu Sans Mono.
- **Сноски «Гаджетотеки».** Точка на детали, подпись, всегда повёрнутая к камере, и выноска на крючках.

Рендер настроен на Workbench, 1920×1080. Объекты различаются только цветом вьюпорта: геометрия серая, титры тёмные, сноски циановые. События, которые в ролике передаются светом (включение телевизора, импульс по кабелю, свечение знака), отмечены маркерами.

### Сцена логотипа

`blender/ETV_logo.blend` — не аниматик, а готовая сцена для рендера в Eevee, с одного ракурса 3/4 сверху. В ней:

- **Логотип** — тёмный графитовый элемент, похожий на корпус игровой консоли: алюминиевый шов, крышка из тёмного стекла, утопленный цифровой экран из пиксельной сетки и индикатор питания.
- **Анимация.** Загорается индикатор, экран просыпается, по сетке, как в игре «Змейка», бежит светящаяся змейка с ярким хвостом и без разрывов обходит контур знака Е. Контур замыкается — знак заливается изнутри, по экрану проходит развёртка, свет экрана ложится на корпус и коврик, знак мягко «дышит». Сила свечения пикселей, подсветки экрана, индикатора и ореола анимирована.
- **Окружение** — стол из заставки канала: тёмный орех и прошитый коврик.
- **Свет** — низкое боковое солнце, контровые, свет экрана, процедурный студийный мир для отражений на стекле и металле.

Рендер настроен на 1920×1080, 30 к/с, с трассировкой отражений, размытием в движении и свечением в композиторе.

Как пересобрать файлы после правок в `index.html`. Нужны Node.js с Playwright и Blender 4.4+:

```bash
node tools/animatic/export.cjs 0 anim/ident    # 0 — заставка, 1 — «Вердикт», 2 — «Гаджетотека», 3 — отбивка, 4 — логотип
blender -b -P tools/animatic/build_blend.py -- anim/ident blender/ETV_animatic_ident.blend \
  tools/animatic/fonts/Unbounded-ExtraBold.ttf tools/animatic/fonts/JetBrainsMono-SemiBold.ttf
```

Сцена логотипа собирается с материалами и светом:

```bash
node tools/animatic/export.cjs 4 anim/logo full
blender -b -P tools/animatic/build_logo_blend.py -- anim/logo blender/ETV_logo.blend \
  tools/animatic/fonts/Unbounded-ExtraBold.ttf tools/animatic/fonts/JetBrainsMono-SemiBold.ttf
```

Шрифты Unbounded и JetBrains Mono распространяются по лицензии SIL Open Font License.

## Версии

Каждая принятая версия пакета лежит в своей ветке, к любой можно вернуться. `main` — всегда последняя.

| Ветка | Что в ней |
| --- | --- |
| `version-1` | Первая версия: стол из модулей с гравировкой, отбивка в стиле Пятого канала |
| `version-2` | Узнаваемые игровые предметы в языке промышленного дизайна: консоль с картриджем, штамп и звёзды оценки, распаковка VR-шлема; крупные финальные титры |
| `version-3` | Своё окружение у каждой заставки (ночной стол игрока, стол критика, предметная студия), больше планов без повторов, крышка коробки в «Гаджетотеке» с первого кадра, новая отбивка с фрезерованным знаком Е |
| `version-4` | Только русский текст в кадре, новая инфографика «Гаджетотеки» (сноски-карточки держатся дольше), аниматики всех роликов в Blender |
| `version-5` | Композиция по правилу третей, плавные камеры и размытие от движения, новый «Вердикт» (штамп ставит оттиск на бланк рецензии, оттиск — финальный титр), новое начало «Гаджетотеки» |
| `version-6` | «Вердикт» как обзор игры: экран «Игра пройдена» с достижением, кнопки геймпада наполняют шкалы категорий, крестовина снимает балл, роликовый счётчик итога 8,5, оттиск «ВЕРДИКТ»; новые движения камеры (орбиты, «вертиго», хлёсткая панорама, кран со спиралью в финал) |
| `version-7` | «Вердикт» снят одним непрерывным планом: плавная камера без склеек, хлёстких панорам и резких наездов |
| `version-8` | «Вердикт»: снова многоплановая камера в стиле других заставок, но с мягкими переходами; плавная анимация печати (без рывков на перелёте и ударе), счётчик итога без проскока |
| `version-9` | Анимация логотипа (объёмный знак Е, 5 с) и её сцена в Blender с материалами и светом; в аниматиках все надписи из роликов текстом того же шрифта и размера |
| `version-10` | Новая анимация логотипа: тёмный корпус с цифровым экраном, знак Е собирает «змейка»; камера с одного ракурса |

```bash
git checkout version-9   # посмотреть девятую версию
git checkout main        # вернуться к последней
```
