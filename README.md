# Е ТВ · 3D-бродкаст-пакет

Эфирное оформление игрового телеканала Е ТВ: заставка канала, заставки рубрик «Вердикт» и «Гаджетотека» по 15 с, отбивка 5 с и анимация логотипа 5 с в двух вариантах: цифровой (знак рисуется на пиксельном экране консоли) и объёмный («Из пикселя в объём»: 8-битный знак выдвигается из панели кубиками и превращается в гладкий объект из акрила и графита). Для обоих вариантов логотипа есть сцены в Blender с материалами и светом. Фирменные цвета: #080A0F, #111722, #00D9FF, #7A35FF.

Все видео 1920×1080, 30 к/с, H.264, без звука.

## Как посмотреть

Откройте `index.html` в браузере. Нужен интернет: Three.js, библиотека polygon-clipping и шрифты грузятся с CDN.

## Как перерендерить видео

Нужны Node.js 18+ и ffmpeg.

```bash
npm install
npx playwright install chromium
npm run render                                # кадры в frames/
for k in 0 1 2 3; do K=$k N=4 node tools/render.cjs & done; wait   # то же в 4 потока
npm run encode                                # MP4 в video/
```

`ONLY=0,3` рендерит только выбранные ролики (0 — заставка канала, 1 — «Вердикт», 2 — «Гаджетотека», 3 — отбивка, 4 — логотип, 5 — логотип в объёме). Готовые кадры пропускаются, прерванный рендер докатывается повторным запуском. Рендер идёт программно, без видеокарты, около 3,5 часа на весь пакет в 4 потока.

## Аниматик в Blender

В папке `blender/` лежат аниматики четырёх роликов (заставка канала, «Вердикт», «Гаджетотека», отбивка) и две сцены анимации логотипа. Аниматики собраны в Blender 4.2 LTS и проверены в 4.2, 4.5 и 5.2: текст, анимация и наложения одинаковы во всех трёх. Сцены логотипа рассчитаны на Eevee и открываются в Blender 5.x.

Что внутри каждого файла:

- **Геометрия.** Вся геометрия ролика без материалов и источников света. Главные предметы подписаны по-русски: «Консоль», «Штамп», «VR-шлем», «Крышка» и так далее.
- **Анимация.** Покадровые ключи всех движущихся предметов, 30 к/с. Появление и исчезновение сделано масштабом.
- **Камера.** Ключи на каждый кадр, склейки без интерполяции. Фокусное расстояние, дистанция фокуса и смещение объектива (shift X/Y, композиция по третям) тоже анимированы.
- **Маркеры.** На шкале времени отмечены склейки «План N» и события монтажного листа.
- **Титры и надписи.** Финальные титры и все надписи из роликов — экраны монитора и портативной консоли, табло оценки, бланк рецензии, этикетки картриджей, гравировки — это текстовые объекты того же шрифта (Unbounded ExtraBold, JetBrains Mono SemiBold), того же размера и на тех же местах, что в ролике. Кегль пересчитан под то, как Blender масштабирует шрифт; ширина строки, межбуквенный интервал, базовая линия и наклон букв титров взяты из измерений браузера. Надписи на экранах, которые меняются по ходу ролика, появляются и исчезают по кадрам. Символы, которых нет в этих шрифтах (▸, ▍), набраны запасным шрифтом DejaVu Sans Mono. Шрифты упакованы внутрь файла.
- **Знак канала.** Знак Е на экране телевизора, этикетке картриджа и экране портативной консоли — плоская фигура по контуру знака из ролика; знак, вытравленный в крышке консоли, и запятая на счётчике итога выделены тёмным.
- **Наложения поверх кадра.** Знак канала в углу, плашка «РЕКЛАМА» (Inter SemiBold — этим шрифтом её набирал браузер) и сноски «Гаджетотеки» — карточки, номера, названия, которые печатаются по буквам, точки, кольца и выноски — лежат в коллекции «Наложение». Она привязана к камере и держит их на тех же местах кадра при любом объективе и смещении.

Рендер настроен на Workbench, 1920×1080. Объекты различаются только цветом вьюпорта: геометрия серая, титры, надписи и знак на корпусе тёмные, знак канала на экранах и в углу, рамки и выноски сносок циановые, карточки сносок тёмные со светлым текстом. События, которые в ролике передаются светом (включение телевизора, импульс по кабелю, свечение знака), отмечены маркерами.

### Сцены логотипа

`blender/ETV_logo.blend` — вариант 1, цифровой. Это не аниматик, а готовая сцена для рендера в Eevee, с одного ракурса 3/4 сверху. В ней:

- **Логотип** — тёмный графитовый элемент, похожий на корпус игровой консоли: алюминиевый шов, крышка из тёмного стекла, утопленный цифровой экран из пиксельной сетки и индикатор питания.
- **Анимация.** Загорается индикатор, экран просыпается, по сетке, как в игре «Змейка», бежит светящаяся змейка с ярким хвостом и без разрывов обходит контур знака Е. Контур замыкается — знак заливается изнутри, по экрану проходит развёртка, свет экрана ложится на корпус и коврик, знак мягко «дышит». Сила свечения пикселей, подсветки экрана, индикатора и ореола анимирована.
- **Окружение** — стол из заставки канала: тёмный орех и прошитый коврик.
- **Свет** — низкое боковое солнце, контровые, свет экрана, процедурный студийный мир для отражений на стекле и металле.

`blender/ETV_logo_obem.blend` — вариант 2, объёмный, «Из пикселя в объём». Это эволюция игровой графики за пять секунд: 8-битная картинка, воксели, гладкое 3D. Камера с одного ракурса, 3/4 спереди слева. В сцене:

- **Знак** — толстая Е с фаской: лицевая сторона из цианового акрила под лаком, бока и фаска из тёмного графита.
- **Пиксельная панель** — графитовый корпус с рамкой из тёмного алюминия на алюминиевой ножке. Экран — сетка из пикселей тёмного стекла. Пиксели знака — отдельные кубики-воксели с графитовыми боками и светящимся торцом.
- **Анимация.** Загорается индикатор. Развёртка сверху вниз рисует на панели 8-битный знак Е, и он мигает, как надпись «нажмите старт». Горящие пиксели волной слева направо выдвигаются из панели кубиками, и знак становится воксельным. По нему проходит световая волна: кубики растворяются, а под ними оказывается гладкий объёмный знак. Акрил загорается, свет знака подсвечивает панель за ним и ложится на стол, по лаку скользит блик.
- **Ключи.** Появление пикселей и растворение кубиков сделаны масштабом. Сила свечения пикселей, волны, акрила, индикатора и ореолов анимирована.
- **Окружение и свет** — те же, что в первом варианте, плюс свет пикселей и знака.

Рендер обеих сцен настроен на 1920×1080, 30 к/с, с трассировкой отражений, размытием в движении и свечением в композиторе.

Как пересобрать файлы после правок в `index.html`. Нужны Node.js с Playwright и Blender 4.2 LTS или новее (сцены логотипа — Blender 5.x):

```bash
node tools/animatic/export.cjs 0 anim/ident    # 0 — заставка, 1 — «Вердикт», 2 — «Гаджетотека», 3 — отбивка, 4 и 5 — логотип
blender -b -P tools/animatic/build_blend.py -- anim/ident blender/ETV_animatic_ident.blend \
  tools/animatic/fonts/Unbounded-ExtraBold.ttf tools/animatic/fonts/JetBrainsMono-SemiBold.ttf tools/animatic/fonts/Inter-SemiBold.otf
```

Сцена логотипа собирается с материалами и светом:

```bash
node tools/animatic/export.cjs 4 anim/logo full
blender -b -P tools/animatic/build_logo_blend.py -- anim/logo blender/ETV_logo.blend \
  tools/animatic/fonts/Unbounded-ExtraBold.ttf tools/animatic/fonts/JetBrainsMono-SemiBold.ttf
```

Объёмный вариант — так же, с номером 5, названием сцены и префиксом файлов рендера:

```bash
node tools/animatic/export.cjs 5 anim/logo3d full
blender -b -P tools/animatic/build_logo_blend.py -- anim/logo3d blender/ETV_logo_obem.blend \
  tools/animatic/fonts/Unbounded-ExtraBold.ttf tools/animatic/fonts/JetBrainsMono-SemiBold.ttf \
  "Логотип Е ТВ · объём" ETV_logo_obem_
```

Шрифты Unbounded, JetBrains Mono и Inter распространяются по лицензии SIL Open Font License. В `tools/animatic/fonts/` лежат официальные выпуски этих шрифтов (Unbounded ExtraBold — статическое начертание веса 800 из вариативного шрифта Google Fonts) со снятыми наложениями контуров: Blender до версии 5 неверно заливает буквы с наложенными контурами, и вместо них выходят треугольники и обрывки. Ширина знаков у шрифтов та же, что в браузере.

| `version-2` | Узнаваемые игровые предметы в языке промышленного дизайна: консоль с картриджем, штамп и звёзды оценки, распаковка VR-шлема; крупные финальные титры |
